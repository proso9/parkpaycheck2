# 停车场异常车辆检测工具

从停车场系统日志中找出**“出场不开闸”且判定窗口内（默认 300 秒）无支付结果下发**的异常车辆，并导出 CSV 结果。

## 功能特性

- **核心检测**（无第三方依赖）：解析系统日志，定位“出场不开闸”且窗口期无同车支付下发的车辆，并反查入场时间、关联用户需支付费用。
- **可疑标记**：对比系统“停车时间”与“入场→出场”实际时长，明显超出的车辆（如门卫遥控放行）额外标记为可疑。
- **图形界面（GUI）**：基于 tkinter，分页配置（路径配置 / 判定参数 / 定时任务 / 运行输出），支持配置导入导出为 JSON。
- **定时任务**：基于 APScheduler，可定时（间隔运行或每天固定时间）自动检测，修改配置后无需重启即生效。
- **系统托盘**：关闭窗口后自动收纳到右下角托盘图标，后台定时任务继续运行；托盘菜单可重新打开或完全退出。

## 环境要求

- Windows 10 / 11
- Python 3.8+

## 依赖安装（Windows）

在项目根目录打开 PowerShell，执行：

```powershell
# 核心检测逻辑无需任何第三方依赖，可直接运行命令行
# 图形界面（定时任务 + 系统托盘）需要安装以下依赖：
python -m pip install apscheduler pystray Pillow
```

各依赖用途：

| 依赖 | 用途 |
| ---- | ---- |
| `apscheduler` | 定时任务调度（间隔运行 / 每天固定时间） |
| `pystray` | 系统托盘图标（关闭窗口后收纳右下角） |
| `Pillow` | 生成托盘图标图像 |

## 快速开始

### 1. 命令行使用

```powershell
# 处理 document/ 下所有日志，默认输出到 output/
python check_unopened_gate.py

# 指定单个日志
python check_unopened_gate.py document\system.2026-08-22.log

# 调整判定窗口(秒)与输出目录
python check_unopened_gate.py -w 300 -o output

# 也可通过模块方式运行
python -m parkcheck.cli -w 300 -o output
```

### 2. 图形界面使用

```powershell
python check_gui.py
```

界面按四个页签组织：

- **路径配置**：设置日志目录、CSV 输出目录。
- **判定参数**：判定窗口(秒)、最小停车时间偏差(分钟)、入场去重窗口(秒)。
- **定时任务**：勾选「启用定时任务」后，按下方配置在后台定时自动检测；支持“间隔运行”（每 N 秒/分/时）与“每天固定时间”（HH:MM）两种方式；状态栏显示下次触发时间。
- **运行输出**：点击「开始检测」执行一次检测，结果实时回显。

其他说明：

- 菜单栏「配置 → 导出/导入配置」可把全部配置（含定时任务）保存为 JSON 或从 JSON 恢复。
- 点击窗口关闭按钮会收纳到系统托盘继续后台运行；托盘菜单「显示主窗口」恢复窗口、「退出程序」完全退出。

### 3. 运行测试

```powershell
# 核心逻辑测试（无第三方依赖）
python -m tests.test_check_unopened_gate

# 定时任务模块测试（依赖 apscheduler）
python -m tests.test_scheduler
```

两套测试均用断言校验，退出码 0 表示全部通过。

## 输出说明

结果写入 `output/` 目录，CSV 命名规则：`异常车辆_<日志日期>.csv`（如处理 `system.2026-08-22.log` 生成 `异常车辆_2026-08-22.csv`）。

输出列：

| 列 | 说明 |
| -- | ---- |
| 入场时间 | 反查到的最近一次入场时间，找不到显示 `-` |
| 出场时间 | 出场不开闸记录的时间 |
| 车牌号 | 归一化（去空格、转大写）后的车牌 |
| 用户需支付费用 | 关联的应付费用，无关联显示 `-` |
| 异常 | `1` 表示系统停车时间明显大于实际时长（可疑，如门卫遥控放行），否则 `0` |

## 工作原理

1. 解析含“出场处理”且“开闸结果：不开闸”的行，得到出场时间 `T` 与车牌。
2. 解析含“==>支付结果下发：”的行，得到支付下发的车牌与时间。
3. 对每条“不开闸”记录，在支付下发中查找**车牌相同且时间在 `[T, T+300 秒]` 窗口内**的记录；找不到则判为异常。
4. 异常车辆反查最近一次入场时间（以相机“方向：入口”扫描为准，5 秒内重复扫描归并为同一次入场）。
5. 对比系统“停车时间”与实际“入场→出场”时长，明显超出的标记为可疑。
